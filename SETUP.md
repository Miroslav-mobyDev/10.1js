# Инструкция по настройке и запуску бота

## Быстрый старт

### 1. Установка зависимостей

```bash
pip3 install python-telegram-bot==20.7 python-dotenv==1.0.0
```

### 2. Настройка конфигурации

Создайте файл `.env`:

```bash
cp .env.example .env
```

Отредактируйте `.env` файл, заменив значения на ваши:

```env
BOT_TOKEN=ваш_токен_бота_от_botfather
ADMIN_ID=ваш_telegram_id
WHATSAPP_GROUP_LINK=https://chat.whatsapp.com/ваша_группа
```

### 3. Запуск

```bash
python3 telegram_bot_improved.py
```

## Получение токена бота

1. Найдите @BotFather в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен в `.env` файл

## Получение вашего Telegram ID

1. Найдите @userinfobot в Telegram
2. Отправьте любое сообщение
3. Скопируйте ваш ID в `.env` файл

## Проверка работы

1. Запустите бота
2. Найдите вашего бота в Telegram
3. Отправьте команду `/start`
4. Проверьте, что бот отвечает

## Возможные проблемы

### Ошибка "No module named 'telegram'"
```bash
pip3 install python-telegram-bot==20.7
```

### Ошибка "No module named 'dotenv'"
```bash
pip3 install python-dotenv==1.0.0
```

### Бот не отвечает
- Проверьте правильность токена
- Убедитесь, что бот запущен
- Проверьте логи на наличие ошибок

### Команды админа не работают
- Проверьте правильность ADMIN_ID
- Убедитесь, что вы являетесь администратором

## Логирование

Бот ведет подробные логи. При проблемах проверьте вывод в консоли для диагностики.
