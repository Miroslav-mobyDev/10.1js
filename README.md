# Telegram Bot для Марафона Восточной Кухни

Этот бот помогает организовать регистрацию участников на кулинарный марафон через Telegram.

## Функции

- 📝 Регистрация участников через диалог
- 💳 Прием и проверка чеков об оплате
- 📱 Сбор контактных данных (имя, телефон)
- 🔗 Автоматическая выдача ссылки на WhatsApp-группу
- 👨‍💼 Административные функции и уведомления
- 📊 Статистика регистраций
- 🛡️ Защита от спама и повторных попыток

## Требования

- Python 3.8+
- Telegram Bot API токен
- WhatsApp группа для участников

## Установка

1. **Клонируйте проект:**
   ```bash
   git clone <your-repo>
   cd <your-repo>
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Настройте переменные окружения:**
   ```bash
   cp .env.example .env
   ```
   
   Отредактируйте файл `.env`:
   ```
   BOT_TOKEN=your_telegram_bot_token
   ADMIN_ID=your_telegram_user_id
   WHATSAPP_GROUP_LINK=https://chat.whatsapp.com/your-group-link
   ```

## Как получить настройки

### 1. Получение токена бота

1. Напишите [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Сохраните полученный токен в `.env` файл

### 2. Получение Admin ID

1. Напишите [@userinfobot](https://t.me/userinfobot)
2. Скопируйте ваш User ID
3. Добавьте его в `.env` файл

### 3. Создание WhatsApp группы

1. Создайте группу в WhatsApp
2. Добавьте участников (администраторов)
3. Откройте настройки группы → "Пригласить в группу по ссылке"
4. Скопируйте ссылку и добавьте в `.env` файл

## Использование

### Для участников:

1. Найдите бота в Telegram и нажмите `/start`
2. Отправьте фото или PDF чека об оплате
3. Введите ваше полное имя
4. Введите номер телефона
5. Получите ссылку на WhatsApp-группу

### Для администратора:

- `/stats` - получить статистику регистраций
- Бот автоматически уведомляет о новых регистрациях
- Уведомления о подозрительной активности
