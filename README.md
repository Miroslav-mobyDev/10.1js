# Telegram Bot для регистрации на марафон восточной кухни

Этот бот предназначен для автоматизации процесса регистрации участников марафона восточной кухни.

## Функциональность

- 📄 Прием чеков об оплате (фото/PDF)
- ✅ Административная проверка чеков
- 👤 Сбор данных участников (имя, телефон)
- 🔗 Автоматическая выдача ссылки на WhatsApp-группу
- 📊 Отслеживание статуса заявки
- 🔄 Система повторных попыток (до 3 раз)

## Установка и запуск

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка переменных окружения

#### Вариант A: Использование .env файла (рекомендуется)

Скопируйте `.env.example` в `.env` и настройте переменные:

```bash
cp .env.example .env
```

Отредактируйте `.env` файл:
```env
BOT_TOKEN=ваш_токен_бота
ADMIN_ID=ваш_telegram_id
WHATSAPP_GROUP_LINK=https://chat.whatsapp.com/ваша_группа
```

#### Вариант B: Переменные окружения

```bash
export BOT_TOKEN="ваш_токен_бота"
export ADMIN_ID="ваш_telegram_id"
export WHATSAPP_GROUP_LINK="https://chat.whatsapp.com/ваша_группа"
```

### 3. Запуск бота

#### Базовая версия:
```bash
python3 telegram_bot.py
```

#### Улучшенная версия (с поддержкой .env):
```bash
python3 telegram_bot_improved.py
```

## Команды бота

### Для пользователей:
- `/start` - Начать регистрацию
- `/help` - Показать справку
- `/status` - Проверить статус заявки
- `/cancel` - Отменить текущее действие

### Для администратора:
- `/approve <user_id>` - Одобрить чек пользователя
- `/reject <user_id>` - Отклонить чек пользователя

## Процесс регистрации

1. **Оплата** - Пользователь оплачивает участие через Kaspi
2. **Отправка чека** - Пользователь отправляет фото/PDF чека боту
3. **Проверка** - Администратор проверяет чек и одобряет/отклоняет
4. **Ввод данных** - После одобрения пользователь вводит имя и телефон
5. **Завершение** - Бот выдает ссылку на WhatsApp-группу
