# 🤖 Telegram Бот для Марафона Восточной Кухни

Этот бот автоматизирует процесс регистрации участников на марафон через проверку чеков об оплате.

## ✨ Возможности

- **✅ Проверка чеков**: Админ проверяет чеки и одобряет/отклоняет их
- **📝 Валидация данных**: Проверка имени и номера телефона
- **🔄 Лимит попыток**: Максимум 3 попытки отправки чека
- **📱 Удобный интерфейс**: Кнопки и интуитивные команды
- **🔐 Безопасность**: Переменные окружения для токенов
- **📊 Статистика**: Команды для проверки статуса заявки

## 🚀 Установка и запуск

### 1. Создание бота в Telegram

1. Напишите [@BotFather](https://t.me/BotFather) в Telegram
2. Создайте нового бота командой `/newbot`
3. Выберите имя и username для бота
4. Сохраните полученный токен

### 2. Получение ID администратора

1. Напишите [@userinfobot](https://t.me/userinfobot) в Telegram
2. Скопируйте ваш ID

### 3. Установка зависимостей

```bash
# Клонируйте или скачайте код
cd ваш-проект

# Создайте виртуальное окружение
python3 -m venv telegram_bot_env

# Активируйте виртуальное окружение
source telegram_bot_env/bin/activate  # Linux/Mac
# или
telegram_bot_env\Scripts\activate     # Windows

# Установите зависимости
pip install -r requirements.txt
```

### 4. Настройка конфигурации

```bash
# Скопируйте пример файла конфигурации
cp .env.example .env

# Отредактируйте файл .env
nano .env  # или любой другой редактор
```

Заполните файл `.env`:
```
BOT_TOKEN=ваш_токен_бота
ADMIN_ID=ваш_telegram_id
WHATSAPP_GROUP_LINK=https://chat.whatsapp.com/ваша-ссылка
```

### 5. Запуск бота

```bash
# Убедитесь, что виртуальное окружение активно
source telegram_bot_env/bin/activate

# Запустите бота
python telegram_bot.py
```

## 📋 Команды бота

### Для пользователей:
- `/start` - Начать регистрацию
- `/help` - Показать справку
- `/status` - Проверить статус заявки
- `/cancel` - Отменить текущее действие

### Для администратора:
- `/approve <user_id>` - Одобрить чек пользователя
- `/reject <user_id>` - Отклонить чек пользователя

## 🔧 Процесс работы

1. **Пользователь** отправляет `/start`
2. **Пользователь** загружает чек об оплате (фото/PDF)
3. **Админ** получает уведомление с чеком
4. **Админ** одобряет или отклоняет чек кнопками
5. При одобрении **пользователь** вводит имя и телефон
6. **Пользователь** получает ссылку на WhatsApp-группу

## 🐛 Устранение неполадок

### Импорты горят красным
```bash
# Убедитесь, что активировано виртуальное окружение
source telegram_bot_env/bin/activate

# Переустановите зависимости
pip install -r requirements.txt
```

### Бот не отвечает
- Проверьте токен в файле `.env`
- Убедитесь, что бот не заблокирован
- Проверьте интернет соединение

### Ошибка "Не установлен BOT_TOKEN"
- Создайте файл `.env` из `.env.example`
- Заполните правильный токен
