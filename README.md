# Telegram Bot для регистрации на марафон

Этот бот предназначен для регистрации участников марафона восточной кухни через Telegram.

## Функциональность

- 📄 Прием чеков об оплате (фото/PDF)
- ✅ Административная проверка чеков
- 👤 Сбор данных участников (имя, телефон)
- 🔗 Выдача ссылки на WhatsApp-группу
- 📊 Отслеживание статуса заявки
- ❌ Система ограничения попыток (3 попытки)

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Настройте переменные окружения:
```bash
export ADMIN_ID="ваш_telegram_id"
export WHATSAPP_GROUP_LINK="https://chat.whatsapp.com/ваша_группа"
```

3. Запустите бота:
```bash
python bot.py
```

## Настройка

### BOT_TOKEN
Токен вашего бота уже установлен в коде. Для безопасности рекомендуется вынести его в переменную окружения:

```bash
export BOT_TOKEN="ваш_токен_бота"
```

### ADMIN_ID
ID администратора в Telegram. Можно узнать через бота @userinfobot

### WHATSAPP_GROUP_LINK
Ссылка на WhatsApp-группу марафона

## Команды бота

### Для пользователей:
- `/start` - Начать регистрацию
- `/help` - Показать справку
- `/status` - Проверить статус заявки
- `/cancel` - Отменить текущее действие

### Для администратора:
- `/approve <user_id>` - Одобрить чек пользователя
- `/reject <user_id>` - Отклонить чек пользователя

## Структура состояний

- `WAITING_FOR_CHECK` - Ожидание отправки чека
- `WAITING_FOR_APPROVAL` - Ожидание подтверждения чека
- `ASK_NAME` - Ввод имени
- `ASK_PHONE` - Ввод телефона
